# Contributing

Focused bug fixes and features are welcome.

1. Use Node.js 22.23.2.
2. Run `npm ci` inside `studio/`.
3. Add or update a behavioral test.
4. Run `npm test`, `npm run typecheck`, and `npm run build`.
5. Do not commit credentials, local projects, personal media, recovery data, or generated builds.

Contributions are submitted under Apache-2.0 unless stated otherwise. Only include code, data, and
media that you have permission to distribute.
