# Support

Use GitHub Issues for reproducible MpVFX bugs and feature proposals after searching existing issues.
Include the application version, operating system, expected result, actual result, and minimal
steps. Logs are useful, but remove usernames, local paths, project media, tokens, and other private
data before attaching them.

Use GitHub Discussions for general workflow questions if Discussions is enabled. Security and
conduct reports must use the private channels described in [SECURITY.md](SECURITY.md) and
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Unsigned local builds are development artifacts and are not supported as official releases.
