# MpVFX v0.0.3

This release brings the timeline and keyframe fixes together with the Vite and Electron
updates, while retaining v0.0.2's local diagnostics and crash recovery.

## Timeline and animation

- Splitting and trimming retain complete native animation curves, including hidden keys,
  Hold interpolation and cubic Bezier handles. The retained portion of each clip keeps its
  original animation, and extending a trim can reveal previously hidden keys again.
- Audio volume and effect envelopes retain their points through split and trim in the
  editor, playback and export adapters.
- Clip Copy, Cut, Paste and Duplicate preserve supported authored properties and animation
  while creating independent identities. Multiple clips retain their relative timing and
  tracks. The clipboard currently operates within the same project and open composition.
- Native-keyframe copy and paste retain values, interpolation and relative spacing. Paste
  checks frame rate, value types and destination collisions before changing the project.
- Select All and Delete All respect timeline/keyframe selection and locked clips. Clipboard,
  split and delete operations commit project changes together, and Undo waits for pending saves.
- Windows keyframe saves now handle Windows paths correctly.

These changes cover the supported animation system, beyond size controls. They do not yet
provide universal effect automation, cross-project clipboard transfer, or ripple/roll/slip/
slide editing. The detailed contracts and remaining work are documented in
[`docs/PROFESSIONAL_TIMELINE_EDITING.md`](https://github.com/marshiyar/mpvfx/blob/v0.0.3/docs/PROFESSIONAL_TIMELINE_EDITING.md).

## Reliability and tooling

- Fixed Linux MOV rendering from saved PNG capture sequences.
- Reduced idle thumbnail memory pressure.
- Integrated Vite 8 with the compatible React plugin and upgraded Electron to 44.4.2.
  Dependency checks now exercise development and production playback in a real browser.
- Retained local diagnostics, crash recovery and **Diagnostics → Save report**. Reports
  stay on the device until manually saved and shared; native memory dumps are excluded.
- Kept intentionally removed repository documentation and optional fixtures optional.
  Packaged licenses, attribution, privacy resources and publication privacy checks remain enforced.

## Downloads and compatibility

Use `MpVFX-0.0.3-arm64.dmg` for Apple Silicon, `MpVFX-0.0.3-x64.dmg` for Intel Macs,
`MpVFX-0.0.3-Setup.exe` for Windows x64, or the `.deb`/`.rpm` for Linux x64.
macOS requires version 15 or newer. The installers are unsigned, and the Mac downloads
are not notarized; publisher warnings may appear. `SHA256SUMS` and the FFmpeg
corresponding-source archive accompany the installers.

Keep a copy of a project when comparing with older builds: earlier readers may reject
the negative or beyond-Out keyframe times now retained by split and trim.

The release pipeline checks packaged export, output pixels, diagnostic redaction, renderer
crashes and restart recovery on all four platform variants before publishing. Source-app
keyframe checks use generated media on hosted runners; they do not establish behavior on
every physical device. Existing full-suite failures involving removed fixtures and unrelated
editor assertions are recorded in the professional timeline document, and are not presented
as a passing full suite.
