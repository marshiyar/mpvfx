# MpVFX v0.0.2

This release adds local diagnostics to make export failures, crashes, slow rendering, and
unexpected editor behavior easier to investigate. It also fixes Windows render helpers
opening terminal windows.

## What changed

- Local telemetry connects editor actions, requests, export jobs, Chromium/FFmpeg/FFprobe
  helpers, errors, GPU state, and performance to the same session.
- Native crash recording and recovery evidence survive an interrupted application session.
- **Diagnostics → Save report** exports a compressed diagnostic report from the sidebar.
  If the editor process crashes, the native error dialog also offers report saving.
- Windows helper launches hide consoles, including GPU detection and quality-analysis
  processes used during rendering.
- Linux's streaming ProRes path decodes PNG captures to raw RGBA before encoding,
  preserving pixels and transparency with the bundled FFmpeg build.

## Privacy

Diagnostics stay on the device until a report is saved and shared manually. The logger does
not collect typed input, clipboard contents, command arguments, or media contents. Known
credential fields, email addresses, and local paths are redacted before disk writes.
Logs are bounded and expire. Native memory dumps are excluded from shareable reports.
No signing credentials, local logs, crash dumps, or personal projects are release assets.

## Test this build

1. Install the download for your platform. Windows uses `MpVFX-0.0.2-Setup.exe`; this is the
   bundled app installer. Linux uses `.deb` or `.rpm`. macOS uses the matching `.dmg`.
2. Reproduce the problem, especially exporting edited clips to MP4 and MOV on Windows.
3. Open **Diagnostics → Save report** and save the `.json.gz` file. After a crash, reopen
   the app first so the report also includes recovery information.
4. Review the report before sharing it, and include the steps taken and expected result.

The release pipeline checks a two-cut MOV export, output pixels, process correlation,
click/error recording, report redaction, a real renderer crash and minidump, and restart
recovery on Windows x64, Linux x64, macOS Apple Silicon, and macOS Intel. This does not
replace testing on real user hardware or guarantee that every GPU/export problem is fixed.

## Installer signing

The GitHub-built installers are unsigned and the Mac downloads are not notarized. Windows
SmartScreen and macOS Gatekeeper may show publisher warnings. Packaging and local diagnostics
do not establish publisher trust; use these downloads for testing. macOS requires macOS 15
or newer. `SHA256SUMS` and the FFmpeg corresponding-source archive accompany the installers.
